# نقشه توسعه و فازبندی

سند مرجع: `MD-RMP-001` · نسخه ۱.۰ · مالک: مدیر محصول

---

## ۱. منطق ترتیب فازها

ترتیب فازها بر اساس **وابستگی داده و ریسک** است، نه بر اساس جذابیت:

```
هسته داده و حسابداری  ← بدون این، هر چیزی که بسازیم روی شن است
        ↓
بانک و Import         ← سریع‌ترین بازگشت سرمایه (صرفه‌جویی ساعتی)
        ↓
باسکول                ← قلب عملیات و منبع حقیقت وزنی
        ↓
انبار                 ← وابسته به باسکول
        ↓
خرید                  ← وابسته به باسکول و انبار
        ↓
فروش                  ← وابسته به انبار
        ↓
صافی و کالا           ← وابسته به فروش
        ↓
BI                     ← وابسته به همه (بدون داده، داشبورد بی‌معنی است)
        ↓
موبایل و آفلاین گسترده
        ↓
هوش مصنوعی
```

## ۲. فازها

### فاز ۰ — معماری (جاری)

| خروجی | معیار پایان |
|---|---|
| سند معماری ۱.۰ (این مجموعه) | همه اسناد `Approved` |
| اسکیمای دیتابیس اولیه | `schema.sql` قابل اجرا |
| قرارداد API | OpenAPI اولیه |
| سیستم طراحی UI | توکن‌ها و ۵ کامپوننت اصلی |
| محیط توسعه و CI | build سبز، تست نمونه |

### فاز ۱ — هسته داده + حسابداری (۸ هفته)

| خروجی | معیار پذیرش |
|---|---|
| Data Core، Audit، Outbox | تست اتمیک و Idempotency |
| Chart of Accounts + سند دوبل | تراز همیشه صفر |
| Posting Engine + ۱۰ قاعده اول | JE-PUR-001، JE-SAL-001/002، JE-TRS-001 |
| گزارش‌های مالی پایه | تراز ۴ ستونه، دفتر کل، ترازنامه |
| قفل دوره | ثبت در دوره بسته ممنوع |
| کاربران و نقش‌ها | ماتریس کامل |

**ریسک اصلی:** مدل حساب‌ها با واقعیت مازندشت هم‌خوان نباشد → بازبینی با حسابرس در هفته دوم.

### فاز ۲ — بانک + Import Studio (۶ هفته)

| خروجی | معیار |
|---|---|
| آپلود، تشخیص الگو، نگاشت، پیش‌نمایش | ۹۰٪ فایل‌های شش بانک |
| حذف تکراری | صفر تکرار در فایل تکراری |
| طبقه‌بندی هوشمند | دقت ≥ ۸۵٪ |
| تطبیق بانکی | مغایرت صفر |
| خزانه و چک | چرخه کامل چک |

**بازگشت سرمایه:** صرفه‌جویی ۲–۴ ساعت در ماه × ۱۲ + کاهش خطا.

### فاز ۳ — باسکول (۸ هفته)

| خروجی | معیار |
|---|---|
| قبض، توزین، سبد، افت | ۴۵ ثانیه |
| اتصال دستگاه + چاپ حرارتی | وزن پایدار و QR |
| آفلاین + همگام‌سازی | ۸ ساعت قطعی |
| انبار ورود + لات | ردیابی |
| گزارش روزانه | جمع وزن مطابق |

**ریسک اصلی:** تنوع سخت‌افزار باسکول → آزمون روی دستگاه واقعی از هفته اول.

### فاز ۴ — انبار و سردخانه (۵ هفته)

موجودی وزنی/شمارشی، انتقال، شمارش، لات، سردخانه، تطبیق انبار و دفتر.

### فاز ۵ — خرید (۴ هفته)

قرارداد باغدار، فاکتور خرید، پیش‌پرداخت، برگشت، Aging باغداران.

### فاز ۶ — فروش (۸ هفته)

تابلوی قیمت، پیش‌فاکتور، سفارش، فاکتور، صافی، تسویه، برگشت، اعتبار، پورسانت.

### فاز ۷ — تولید و بسته‌بندی (۵ هفته)

سورت، بسته‌بندی، ضایعات، بهای تمام‌شده، راندمان، دستمزد خط.

### فاز ۸ — BI و گزارش (۵ هفته)

داشبورد، KPIها، سود هر تن/مشتری/محصول/باغ/سردخانه، پیش‌بینی نقدینگی، گزارش‌ساز.

### فاز ۹ — موبایل و پشتیبانی میدانی (۴ هفته)

PWA، تبلت انبار، دسترسی مدیر، اعلان‌ها، Help Center کامل.

### فاز ۱۰ — هوش مصنوعی تحلیل مالی (پس از ۲ سال داده)

| قابلیت | پیش‌نیاز داده |
|---|---|
| پیش‌بینی قیمت فصلی | ۲۴ ماه تاریخ قیمت |
| پیشنهاد زمان فروش | لات‌های تاریخی + قیمت |
| تشخیص ناهنجاری (تقلب/خطا) | ۱۲ ماه تراکنش |
| پیش‌بینی نقدینگی هوشمند | ۲۴ ماه جریان نقدی |

## ۶. ریسک‌ها و پاسخ
