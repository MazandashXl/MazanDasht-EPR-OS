## ۶. برنامه UAT (پذیرش کاربر)

| روز | کاربر | کار | معیار |
|---|---|---|---|
| ۱ | اپراتور باسکول | ۲۰ قبض واقعی | ≤ ۴۵ ثانیه، صفر خطای وزن |
| ۲ | انباردار | ۱۰ حواله + یک شمارش | بدون کمک |
| ۳ | فروشنده | ۵ فاکتور با صافی | ≤ ۳ دقیقه |
| ۴ | حسابدار | یک ماه بانک + تطبیق | ≤ ۱۰ دقیقه |
| ۵ | مدیر | داشبورد و ۳ Drill-down | یافتن منبع هر عدد |
| ۶ | حسابرس | تراز، سند نمونه، Audit | تأیید مستندسازی |

**فرم بازخورد:** برای هر گام: موفق / با کمک / ناموفق + زمان + مانع. هر مانع، به بک‌لاگ با اولویت منتقل می‌شود.
