# ماژول تولید، سورت و بسته‌بندی

سند مرجع: `MD-MOD-PRD-001` · نسخه ۱.۰ · مالک: متخصص صنعت مرکبات · بازبین: مهندس UX، حسابرس

---

## ۱. هدف

تبدیل «۱۷٫۵ تن پرتقال فله» به «۱٬۰۰۰ کارتن درجه یک + ۳۰۰ کارتن درجه دو + ۶۰۰ کیلو ضایعات»، با پاسخ به سه پرسش:

1. **راندمان چقدر بود؟** (`yield_pct`)
2. **هر کارتن چقدر تمام شد؟** (`cost_per_carton`)
3. **بار هر کارتن از کدام باغ آمد؟** (`lot traceability`)

## ۳. محاسبه بهای تمام‌شده

```
lot_cost = purchase_cost_lot
         + inbound_freight
         + sort_labor
         + pack_labor
         + cartons_consumed_cost
         + packaging_materials
         + cold_storage_allocated
         + utilities_allocated
         − by_product_credit (اختیاری، ۰ در نسخه ۱.۰)

cost_per_kg_finished = lot_cost / Σ packed_kg
cost_per_carton      = cost_per_kg_finished × carton_net_weight_kg
```

**تخصیص هزینه‌های مشترک (سردخانه، برق، سرپرست خط):**

| مبنا | انتخاب پیش‌فرض | دلیل |
|---|---|---|
| سردخانه | `kg × روز نگهداشت` | مصرف واقعی فضا و زمان |
| برق | `kg` پردازش‌شده | همبستگی با حجم کار |
| دستمزد مستقیم | ساعت کارکرد خط | واقعی‌ترین |
| هزینه اداری | سهم مساوی ماهانه | ساده و قابل توضیح |

**قاعده:** مبنا در `sys_allocation_basis` تعریف می‌شود؛ تغییر آن برای دوره جدید اعمال می‌شود، نه گذشته.

## ۴. فرآیند

```
[دستور کار] ──► [سورت] ──► [خروجی درجه A/B/C + ضایعات] ──► [بسته‌بندی]
                                                             │
                                          [مصرف کارتن/مواد] ─┘
                                                             ▼
                                            [بهای تمام‌شده لات جدید]
                                                             ▼
                                        [JE-PRD-001 + لات آماده فروش]
```

| گام | ثبت | کنترل |
|---|---|---|
| دستور کار | لات ورودی، محصول هدف | موجودی کافی |
| سورت | وزن خروجی هر درجه | `yield + waste ≤ 100%` |
| بسته‌بندی | تعداد کارتن، کارتن مصرفی | کارتن موجود |
| بستن لات | بهای واحد | همه هزینه‌ها تخصیص یافته |
| ثبت | JE-PRD-001 | تراز و ابعاد |

## ۶. کارکرد پرسنل و دستمزد

| روش | محاسبه |
|---|---|
| روزمزد | روزهای حضور تأییدشده × نرخ روز |
| ساعتی | ساعت شیفت × نرخ |
| کارمزدی | `kg` پردازش‌شده × نرخ کیلو |
| ترکیبی | پایه + پاداش راندمان |

دستمزد خط بر اساس `prd_shift.operator_hours` و `prd_sort_run` تخصیص می‌یابد و در JE-PRD-001 به بهای لات می‌رود.

## ۸. KPIهای مرتبط

| KPI | فرمول | هدف |
|---|---|---|
| راندمان سورت | `packed_kg / input_kg` | ≥ ۸۵٪ |
| نرخ ضایعات | `waste_kg / input_kg` | ≤ ۵٪ |
| کارتن مصرفی به ازای تن | `cartons / (packed_kg/1000)` | طبق استاندارد |
| بهره‌وری نفر-ساعت | `kg / operator_hours` | روند صعودی |
| توقف خط | دقیقه/شیفت | ≤ ۳۰ |
