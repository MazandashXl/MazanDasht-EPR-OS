# ماژول خرید

سند مرجع: `MD-MOD-PUR-001` · نسخه ۱.۰ · مالک: متخصص صنعت مرکبات · بازبین: حسابرس مالی

---

## ۱. دامنه

| نوع خرید | منبع | ویژگی |
|---|---|---|
| میوه از باغدار | قبض باسکول | وزن، سبد، افت، فی فصلی |
| میوه از دلال/واسطه | قبض + کمیسیون | کمیسیون خرید |
| کارتن و مواد بسته‌بندی | فاکتور تأمین‌کننده | شمارشی، سری، حداقل سفارش |
| سبد و پالت | فاکتور/امانی | برگشت‌پذیر |
| خدمات (حمل، سورت قراردادی، تعمیر) | فاکتور خدماتی | بدون موجودی |
| دارایی ثابت | فاکتور + پرونده دارایی | استهلاک |

---

## ۲. قرارداد خرید با باغدار

قرارداد، «حافظه سیستم» از توافق شفاهی است و از اختلاف فصلی جلوگیری می‌کند.

| فیلد | نمونه |
|---|---|
| `party_id` / `garden_id` | باغ رضایی — آمل |
| `item_id` / `variety` | پرتقال تامسون |
| `season` | ۱۴۰۴/۰۷ تا ۱۴۰۴/۱۲ |
| `pricing_method` | `FIXED_PER_KG` / `MARKET_DAILY` / `FORMULA` |
| `base_price` | ۱۸٬۰۰۰ ریال |
| `loss_pct` | ۲٪ (با امکان پله‌ای) |
| `basket_rule` | «سبد قرمز ۲٫۸ کیلو، تعداد اعلامی باغدار» |
| `payment_term_days` | ۳۰ روز |
| `advance_allowed` | حداکثر ۳۰٪ مبلغ |
| `quality_terms` | حداکثر ۵٪ درجه دو |
| `freight_borne_by` | `BUYER` / `SELLER` |

**قاعده:** قبض باسکول، افت و فی پیش‌فرض را از قرارداد می‌گیرد؛ تغییر هرکدام نیازمند دلیل و ثبت در قبض است (BR-304).

```

                                                          │
                                                          ▼
                                            [فاکتور خرید (فی + افت + سبد)]
                                                          │
                                          ┌───────────────┼───────────────┐
                                          ▼               ▼               ▼
                                     [ثبت + سند]    [تسویه/پیش‌پرداخت]  [برگشت]
```

| گام | کنترل |
|---|---|
| سفارش خرید | تعهد (حساب انتظامی ۶۱۰۵)، بدون اثر ریالی |
| باسکول | وزن و افت (بخش باسکول) |
| فاکتور | فی از قرارداد یا تابلوی خرید روز |
| ثبت | JE-PUR-001 (و JE-PUR-002 برای حمل سرمایه‌شده) |
| تسویه | نقد/چک/تهاتر با پیش‌پرداخت |

## ۸. پذیرش

- [ ] تبدیل قبض باسکول به فاکتور خرید با یک کلیک، بدون ورود مجدد وزن.
- [ ] افت و فی از قرارداد پیش‌فرض شوند و تغییر آن‌ها دلیل بخواهد.
- [ ] پیش‌پرداخت در همان سند تهاتر و مانده واقعی باغدار نمایش داده شود.
- [ ] حمل سرمایه‌شده به بهای موجودی اضافه و در COGS نهایی لحاظ شود.
- [ ] برگشت، موجودی و بدهی را با هم اصلاح کند.
