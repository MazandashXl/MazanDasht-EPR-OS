## ۱. دامنه

| زیرماژول | محتوا |
|---|---|
| خزانه | صندوق‌ها، تنخواه، دریافت، پرداخت، حواله، تسویه ترکیبی |

## ۳. چرخه‌های حیات

### ۳.۱ چک دریافتی

```
RECEIVED ──(واریز به بانک)──► IN_COLLECTION ──(وصول)──► CLEARED
    │                              │
    └──(خرج‌کردن/پشت‌نویسی)──► ENDORSED          └──(برگشت)──► BOUNCED ──► RETURNED
```

| انتقال | اثر |
|---|---|
| RECEIVED | Dr `11042` / Cr دریافتنی + انتظامی `6101`/`6102` |
| IN_COLLECTION | Dr `11041` / Cr `11042` |
| CLEARED | Dr بانک / Cr `11041` + آزادسازی انتظامی |
| BOUNCED | Dr دریافتنی / Cr `11041` + هشدار اعتباری مشتری |
| ENDORSED | انتقال چک به تأمین‌کننده با پشت‌نویسی |

### ۳.۲ چک پرداختی

```
ISSUED ──(ارائه به بانک)──► PRESENTED ──(پاس)──► CLEARED
   │                                          └──(برگشت)──► BOUNCED ──► REISSUED
   └──(ابطال/امانی)──► CANCELLED
```

## ۴. فرآیند و کنترل‌ها

| فرآیند | کنترل اجباری |
|---|---|
| دریافت نقدی | شمارش صندوق در پایان روز |
| دریافت چک | ثبت تصویر چک، کنترل تاریخ/مبلغ/امضا |
| پرداخت نقدی > سقف | تأیید مدیر مالی |
| صدور چک | کنترل مانده، سرسیدگیری خودکار، تأیید دوگانه بالای سقف |
| پرداخت گروهی | ساخت فایل بانک (SEPA/شتاب/فایل اکسل بانک)، تأییدکننده ≠ سازنده |
| انتقال بین بانک | کنترل مانده مبدأ |
| تطبیق ماهانه | مانده دفتر = مانده بانک پس از اقلام در جریان |

**قاعده تفکیک وظایف (VIS-10):**

| نقش | مجاز |
|---|---|
| کارشناس خزانه | ثبت رسید/پرداخت، چاپ چک |
| مدیر مالی | تأیید پرداخت، تأیید تطبیق |
| مدیرعامل | تأیید پرداخت بالای سقف |

هیچ کاربری نمی‌تواند سند پرداخت را هم بسازد و هم تأیید کند.

## ۵. تطبیق بانکی

```
مانده دفتری (دفتر کل حساب بانک)
   + واریزهای در راه
   − چک‌های صادرشده پاس‌نشده
   = مانده تعدیل‌شده
   باید برابر باشد با: مانده بانک طبق صورتحساب − اقلام بانکی ثبت‌نشده
```

| وضعیت قلم | معنی | اقدام |
|---|---|---|
| Matched | سند و ردیف بانکی منطبق | — |
| Outstanding deposit | واریز در راه | پیگیری ۲ روزه |
| Outstanding cheque | چک پاس‌نشده | پیگیری ۳۰ روزه |
| Bank-only | در بانک هست، در دفتر نیست | ثبت از Import |
| Book-only | در دفتر هست، در بانک نیست | بررسی |

گزارش `RPT-BNK-003` و `RPT-BNK-004`. دوره بسته نمی‌شود تا مغایرت صفر شود، مگر با تأیید و یادداشت.
