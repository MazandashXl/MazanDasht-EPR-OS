# ماژول پرسنل و حقوق

سند مرجع: `MD-MOD-HR-001` · نسخه ۱.۰ · مالک: مدیر محصول · بازبین: حسابرس مالی

---

## ۱. دامنه

| بخش | محتوا |
|---|---|
| پرونده پرسنلی | مشخصات، قرارداد، سمت، مرکز هزینه، حساب بانکی، بیمه |
| حضور و غیاب | ورود/خروج، مرخصی، اضافه‌کاری، غیبت |
| حقوق و دستمزد | محاسبه، بیمه، مالیات، کسورات، پرداخت |
| کارگران فصلی خط | روزمزد/ساعتی/کارمزدی با اتصال به راندمان |
| وام و مساعده | اقساط و کسر از حقوق |

## ۲. مدل داده

| جدول | نقش |
|---|---|
| `hr_employee` | پرسنل: کد، نام، کد ملی، سمت، تاریخ استخدام، نوع قرارداد |
| `hr_contract` | قرارداد: نوع، حقوق پایه، مزایا، تاریخ شروع/پایان |
| `hr_attendance` | حضور روزانه: ورود، خروج، تأخیر، اضافه‌کاری |
| `hr_leave` | مرخصی و مأموریت |
| `hr_payroll_run` | دوره حقوق (ماه) با وضعیت |
| `hr_payslip` / `hr_payslip_line` | فیش حقوقی و اجزا |
| `hr_loan` | وام/مساعده و اقساط |
| `hr_insurance_rate`, `hr_tax_bracket` | نرخ‌ها و پله‌های مالیات (نسخه‌دار) |

### ۲.۱ `hr_employee`
`code`, `first_name`, `last_name`, `national_id`, `father_name`, `birth_date`, `hire_date`, `termination_date`, `position_id`, `cost_center_id`, `contract_type` (`PERMANENT`, `TEMPORARY`, `SEASONAL`, `DAILY`), `base_salary`, `bank_account`, `insurance_no`, `status`.

## ۳. فرمول محاسبه حقوق

```
gross = base_salary
      + housing_allowance + food_allowance + family_allowance
      + overtime_pay + shift_pay + production_bonus

overtime_pay    = hourly_rate × coefficient(1.4) × overtime_hours
production_bonus= kg_processed × bonus_rate

insurance_employee = min(gross, ceiling) × 7%
insurance_employer = min(gross, ceiling) × 23%
tax                = progressive(gross − insurance_employee − exemptions)

net = gross − insurance_employee − tax − loans_installment − advances − other
```

نرخ‌ها و سقف‌ها در `hr_insurance_rate` و `hr_tax_bracket` با `effective_from` نگه داشته می‌شوند. **هیچ نرخی در کد سخت‌کد نمی‌شود** (BR-562).

### ۳.۱ کارگر خط (فصلی)

| روش | محاسبه | داده منبع |
|---|---|---|
| روزمزد | روزهای تأییدشده × نرخ روز | `hr_attendance` |
| ساعتی | ساعت شیفت × نرخ | `prd_shift` |
| کارمزدی | `kg` پردازش × نرخ | `prd_sort_run` |
| ترکیبی | پایه + پاداش راندمان | هر دو |

## ۴. فرآیند دوره حقوق

```
1. قفل حضور ماه (HR)
2. تولید پیش‌نویس حقوق (محاسبه خودکار)
3. بازبینی و اصلاح دستی با دلیل
4. تأیید مدیر مالی (SoD: اجراکننده ≠ تأییدکننده)
5. سند حسابداری: JE-HR-001
6. پرداخت (فایل بانک) → JE-HR-002
7. صدور فیش حقوقی (PDF با QR)
8. ثبت در سابقه و قفل دوره
```

| وضعیت `hr_payroll_run` | معنی |
|---|---|
| `DRAFT` | در محاسبه |
| `CALCULATED` | محاسبه‌شده، قابل بازبینی |
| `APPROVED` | تأیید مالی |
| `POSTED` | سند ثبت شد |
| `PAID` | پرداخت شد (قفل) |
