## ۳. استهلاک

```
monthly_depreciation = (cost − salvage) / useful_life_months
accumulated += monthly_depreciation
book_value = cost − accumulated
```

| قاعده | جزئیات |
|---|---|
| اجرا | ماهانه، قبل از بستن دوره |
| ثبت | JE-AST-001 (Dr `5301` / Cr `1307`) |
| تغییر برآورد | فقط برای دوره‌های آینده (prospective) |
| توقف استهلاک | دارایی `DISPOSED` یا استهلاک‌کامل‌شده |
| کنترل | مانده `1307` = جمع استهلاک همه دارایی‌ها |
