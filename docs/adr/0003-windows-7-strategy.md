# ADR-0003 — راهبرد Windows 7

- تاریخ: ۱۴۰۴/۰۸/۰۲ · وضعیت: **Accepted**
- تصمیم‌گیرندگان: مهندس شبکه، معمار ERP، مدیر محصول
- مرتبط: REQ-N-009، ARC

## زمینه
درخواست پشتیبانی Win7 وجود دارد. واقعیت فنی: .NET 8 روی Win7 اجرا نمی‌شود؛ Electron 23+ هم. آخرین Electron سازگار، نسخه ۲۲ (Chromium 108) است که خودش هم پشتیبانی امنیتی نمی‌گیرد.

## گزینه‌ها
1. **پشتیبانی کامل Win7** — نیازمند .NET Framework 4.8 + Electron 22؛ قربانی‌دادن LTS و امنیت.
2. **عدم پشتیبانی Win7** — ساده‌ترین، اما چند ایستگاه باسکول از کار می‌افتند.
3. **پشتیبانی محدود** — سرور روی Win2016+/Ubuntu؛ Win7 فقط کلاینت Electron 22 با بیلد ES2019.

## تصمیم
گزینه ۳:
- سرور هرگز روی Win7 اجرا نمی‌شود.
- Win7 فقط کلاینت نمایش/ورود، Electron 22، بدون SQLite محلی پیشرفته و بدون به‌روزرسانی خودکار.
- بیلد جداگانه با `target: es2019` و بدون WebSocket اجباری (Polling).
- برنامه مهاجرت به Win10 تا پایان ۱۴۰۵ اعلام می‌شود.

## پیامدها
- مثبت: حفظ عملیات موجود بدون قربانی‌کردن معماری سرور.
- منفی: دو بیلد فرانت‌اند، سطح امنیتی پایین‌تر کلاینت Win7، هزینه آزمون.
- بازبینی: شمارش واقعی دستگاه‌های Win7 در فاز ۳؛ اگر ≤ ۲ دستگاه، حذف پشتیبانی.
