# ADR-0005 — الزام دوبل در سطح دیتابیس

- تاریخ: ۱۴۰۴/۰۸/۰۲ · وضعیت: **Accepted**
- تصمیم‌گیرندگان: حسابرس ارشد، معمار ERP
- مرتبط: VIS-01، BR-001، BR-002

## زمینه
قاعده «هیچ سندی بدون سند متوازن» باید غیرقابل‌دور زدن باشد، حتی با اسکریپت مستقیم.

## گزینه‌ها
1. کنترل فقط در Application.
2. کنترل در Application + Constraint/Trigger در DB.
3. استفاده از جدول خطوط فقط-افزودنی با بازسازی مانده.

## تصمیم
گزینه ۲ + ۳:
- `CHECK (total_debit = total_credit)` روی سرآمد.
- Trigger پس از درج/ویرایش خط، جمع را کنترل و سرآمد را به‌روز می‌کند.
- Trigger تغییرناپذیری: هیچ UPDATE/DELETE روی سند با وضعیت POSTED/REVERSED.
- Trigger حساب برگ و دوره باز.
- زنجیره هش برای تشخیص دستکاری خارج از برنامه.

## پیامدها
- مثبت: تضمین ساختاری؛ حسابرسی قابل اتکا.
- منفی: هزینه Trigger در درج انبوه (Import) → درج در حالت `DEFERRABLE` یا bulk با کنترل دسته‌ای.
- بازبینی: اندازه‌گیری کارایی Import ۵٬۰۰۰ ردیف.
