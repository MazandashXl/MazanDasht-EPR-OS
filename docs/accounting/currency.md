# ماژول ارز و چندارزی

سند مرجع: `MD-ACC-004` · نسخه ۱.۰ · مالک: حسابرس مالی ارشد · بازبین: معمار ERP

---

## ۱. الزام محصول

> بالای برنامه، یک انتخابگر ارز: ریال · تومان · دلار · یورو · درهم · لیر · واحد سفارشی.
> با یک کلیک، **کل نرم‌افزار** واحد پول نمایش را عوض می‌کند — بدون تغییر داده و بدون Reload.

---

## ۲. مدل داده

### ۲.۱ `core_currency`

| فیلد | نمونه | توضیح |
|---|---|---|
| `code` | `IRR`, `USD`, `EUR`, `AED`, `TRY` | ISO یا کد سفارشی |
| `name_fa` | ریال ایران | — |
| `symbol` | `﷼` | نماد نمایش |
| `decimal_places` | ۰ برای IRR، ۲ برای USD | دقت نمایش |
| `rounding` | `HALF_UP` | سیاست گرد کردن |
| `is_base` | `true` برای IRR | ارز پایه حسابداری |
| `display_unit` | `TOMAN` برای IRR | واحد نمایش پیش‌فرض |
| `display_ratio` | `10` | ۱ تومان = ۱۰ ریال |
| `format_mask` | `#,##0` | قالب چاپ |
| `is_active` | true | — |

### ۲.۲ `core_currency_display_unit`

| فیلد | نمونه |
|---|---|
| `currency_id` | IRR |
| `code` | `TOMAN` |
| `name_fa` | تومان |
| `ratio` | ۱۰ |
| `decimal_places` | ۰ |
| `symbol` | تومان |

### ۲.۳ `core_exchange_rate`

| فیلد | توضیح |
|---|---|
| `currency_id` | ارز خارجی |
| `rate` | ۱ واحد ارز = چند ریال |
| `effective_from` / `effective_to` | بازه اعتبار |
| `source` | `MANUAL`, `BANK`, `CBI`, `CONTRACT` |
| `rate_type` | `SPOT`, `CONTRACT`, `CUSTOMS` |

**قاعده:** هر سند ارزی، نرخ خود را با `fx_rate` **Snapshot** می‌کند. تغییر نرخ فردا، سند دیروز را تغییر نمی‌دهد (BR-015).

---

## ۳. قاعده دو-مبلغی

هر خط سند ارزی، **دو** مقدار دارد:

```
amount_fx   = ۱۰۰٬۰۰۰ USD
fx_rate     = ۶۰۰٬۰۰۰ ریال
amount_base = ۶۰٬۰۰۰٬۰۰۰٬۰۰۰ ریال
```

| موضوع | قاعده |
|---|---|
| تراز | بر `amount_base` کنترل می‌شود |
| گزارش ارزی | بر `amount_fx` با نرخ سند |
| مانده ارزی | جداگانه بر حسب ارز نگه داشته می‌شود |
| تسعیر | پایان دوره، اختلاف به `5303`/`4109` |

---

## ۴. تغییر واحد نمایش (بدون تغییر داده)

```
انتخاب کاربر: [تومان ▾]  →  کش UI: display_unit = TOMAN, ratio = 10
نمایش: مبلغ پایه ÷ ratio  با decimal_places واحد
```

| نکته | جزئیات |
|---|---|
| ورود داده | همیشه در واحد انتخاب‌شده تفسیر و به پایه تبدیل می‌شود؛ تبدیل در لبه UI و ثبت پایه در API |
| گزارش‌ها | از تنظیم کاربر یا تنظیم سازمان پیروی می‌کنند |
| چاپ | واحد در سرصفحه و در کنار هر جمع نوشته می‌شود |
| مبالغ بزرگ | در تومان با «م» (میلیون) در داشبورد، در گزارش کامل |
| هیچ‌گاه | تغییر واحد، مقدار ذخیره‌شده را تغییر نمی‌دهد |

---

## ۵. ورود مبلغ با واحد صریح

```
[۳۲٬۰۰۰] [تومان ▾]   ← کاربر می‌تواند «ریال» انتخاب کند
تبدیل: ۳۲۰٬۰۰۰ ریال → ذخیره amount_base
نمایش کمکی: «سیصد و بیست هزار ریال»
```

**قاعده ضدخطا:** اگر واحد انتخابی با تنظیم صفحه متفاوت باشد، فیلد زرد و برچسب واحد برجسته می‌شود.

---

## ۶. صادرات و واردات

| مورد | قاعده |
|---|---|
| فاکتور صادراتی | ارز سند + نرخ Snapshot + اینکوترمز + مدارک |
| خرید ارزی | نرخ ثبت سفارش/کوتاژ |
| گزارش ارزی | مانده بر حسب ارز اصلی + معادل ریالی |
| اختلاف تسعیر | پایان دوره + سند جداگانه |
| محدودیت | سند ارزی نمی‌تواند دو ارز داشته باشد (BR-014) |
