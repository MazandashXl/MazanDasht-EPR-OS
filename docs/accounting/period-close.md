# بستن دوره و سال مالی

سند مرجع: `MD-ACC-005` · نسخه ۱.۰ · مالک: حسابرس مالی ارشد · بازبین: معمار ERP

> هدف: بستن ماهانه در **≤ ۳ روز** و بستن سال بدون یک ریال اختلاف. بستن، یک رویداد «تشریفاتی» نیست؛ یک **کنترل کیفیت** است.

---

## ۱. تقویم مالی

| موضوع | تعریف |
|---|---|
| سال مالی | ۱ فروردین تا ۲۹/۳۰ اسفند |
| دوره | ماه شمسی (`1404/07`) |
| وضعیت دوره | `OPEN` → `SOFT_CLOSED` → `CLOSED` → `LOCKED` |
| ثبت در `OPEN` | مجاز |
| ثبت در `SOFT_CLOSED` | فقط با مجوز `sys.period.reopen` و لاگ |
| ثبت در `CLOSED` | ممنوع؛ فقط سند اصلاحی با مجوز مدیر مالی |
| `LOCKED` | فقط با مجوز مدیرعامل + بازگشایی رسمی |

## ۳. فرآیند بستن ماه

```
D-3  ارسال یادآوری به همه نقش‌ها (چک‌لیست)
D-1  اجرای کنترل‌های خودکار + گزارش «آمادگی بستن»
D0   بازبینی استثناها → تأیید مدیر مالی → SOFT_CLOSED
D+1  ثبت اصلاحات مجاز، سپس CLOSED + قفل
D+2  صدور گزارش‌های ماهانه (تراز، سود و زیان، جریان نقدی)
```

## ۴. بستن سال

```
1. بستن ۱۲ دوره (همه CLOSED)
2. اجرای تسعیر ارز پایان سال
3. کنترل نهایی: ترازنامه متوازن، سود و زیان محاسبه‌شده
4. سند بستن (JE-CLS-002): انتقال درآمدها و هزینه‌ها به سود انباشته
5. ایجاد سال مالی جدید + سند افتتاحیه (مانده دائمی‌ها)
6. کنترل: مانده افتتاحیه = مانده پایانی سال قبل (تست خودکار، اختلاف = ۰)
7. قفل سال (LOCKED) + آرشیو
```

### ۴.۱ سند افتتاحیه

| # | حساب | Dr | Cr |
|---|---|---|---|
| 1 | همه حساب‌های دارایی (مانده بدهکار) | مانده | — |
| 2 | همه حساب‌های بدهی و سرمایه (مانده بستانکار) | — | مانده |
| 3 | `3102` سود انباشته | — | مانده سود |

**قاعده:** سند افتتاحیه فقط یک بار در سال ایجاد می‌شود؛ اصلاح آن نیازمند مجوز مدیر مالی و سند اصلاحی است.

## ۵. بازگشایی

| حالت | مجوز | اثر | لاگ |
|---|---|---|---|
| SOFT_CLOSED → OPEN | `sys.period.reopen` | ثبت مجاز | اجباری |
| CLOSED → OPEN | مدیر مالی + دلیل | ثبت مجاز، هشدار به همه | اجباری + گزارش |
| LOCKED → OPEN | مدیرعامل + دلیل | — | اجباری + گزارش به حسابرس |

هر بازگشایی، فهرست اسناد ثبت‌شده پس از بستن را نشان می‌دهد تا اثر آن قابل ارزیابی باشد.

## ۶. داده‌ها و وضعیت‌ها

```sql
CREATE TABLE core_fiscal_period (
  id uuid PRIMARY KEY,
  fiscal_year_id uuid NOT NULL REFERENCES core_fiscal_year(id),
  code varchar(7) NOT NULL,          -- 1404/07
  start_date date NOT NULL,
  end_date date NOT NULL,
  status smallint NOT NULL DEFAULT 0, -- 0 OPEN,1 SOFT_CLOSED,2 CLOSED,3 LOCKED
  closed_at timestamptz,
  closed_by uuid,
  UNIQUE (fiscal_year_id, code)
);

CREATE TABLE fin_period_close_exception (
  id uuid PRIMARY KEY,
  period_id uuid NOT NULL REFERENCES core_fiscal_period(id),
  control_code varchar(40) NOT NULL,
  reason text NOT NULL,
  approved_by uuid NOT NULL,
  approved_at timestamptz NOT NULL DEFAULT now()
);
```
