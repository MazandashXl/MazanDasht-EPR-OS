## ۴. انتخاب ستون چاپ

کاربر در پیش‌نمایش، ستون‌ها را تیک می‌زند و قالب را ذخیره می‌کند:

```
☑ تلفن   ☑ آدرس   ☐ کد اقتصادی   ☐ موجودی   ☐ لات   ☑ وزن سبد   ☐ نام راننده
[ذخیره به‌عنوان «فاکتور بارفروش»]
```

| قاعده | جزئیات |
|---|---|
| ستون‌های اجباری | محصول، وزن خالص، فی، مبلغ، جمع، مبلغ نهایی |
| ستون‌های اختیاری | تلفن، آدرس، کد اقتصادی، موجودی، لات، سبد، راننده، پلاک، توضیح |
| قالب‌ها | چند قالب برای یک سند (مثلاً «فاکتور بارفروش» و «فاکتور صادراتی») |
| مجوز | `prt.template.manage` برای ساخت قالب مشترک؛ هر کاربر قالب شخصی |
| تعداد ستون | حداکثر ۱۲ ستون در A4 عمودی؛ بیشتر → A3 یا ستون‌های ریز |

## ۵. هویت بصری

| عنصر | انتخاب | دلیل |
|---|---|---|
| رنگ اصلی | سبز مرکباتی تیره (`#1B5E20`) | ارتباط صنفی + خوانایی چاپ |
| رنگ ثانویه | نارنجی (`#EF6C00`) | تأکید، هشدار |
| رنگ خطا | قرمز (`#C62828`) | — |
| فونت متن | Vazirmatn / IRANSans | خوانایی فارسی، اعداد فارسی |
| فونت عدد | Vazirmatn Medium + tabular | هم‌ترازی ستون‌های عددی |
| سرصفحه جدول | پس‌زمینه سبز کم‌رنگ، متن تیره | خوانایی چاپ سیاه‌وسفید |
| چاپ تک‌رنگ | همه اسناد باید در چاپ سیاه‌وسفید هم خوانا باشند | چاپگرهای حرارتی/لیزری قدیمی |
| حداقل فونت | ۸pt برای جدول، ۱۰pt برای متن | خوانایی |

## ۶. QR و اعتبارسنجی سند

```
payload = TYPE|CODE|HASH6
نمونه:   SAL|S14-002381|9f2a1c
```

- اسکن QR در اپ موبایل/وب → صفحه اعتبارسنجی عمومی → نمایش خلاصه سند (بدون اطلاعات محرمانه).
- `HASH6` از `invoice_hash` گرفته می‌شود؛ تغییر مبلغ، هش را باطل می‌کند.
- صفحه اعتبارسنجی، فقط: شماره، تاریخ، مبلغ کل، وضعیت (معتبر/باطل)، نام صادرکننده.

## ۷. مهر دیجیتال و امضا

| موضوع | نسخه ۱.۰ |
|---|---|
| امضای تصویری | تصویر امضای مجاز در `sys_signature`، محدود به نقش |
| مهر دیجیتال داخلی | هش سند + کلید داخلی، درج `SEAL` در PDF |
| امضای الکترونیک قانونی (گواهی) | خارج از دامنه ۱.۰ (وابسته به ارائه‌دهنده گواهی) |
| اثر انگشت چاپ | ثبت `wb_print_log`/`doc_print_log` برای هر چاپ با کاربر و زمان |

## ۸. چاپ حرارتی (قبض باسکول)

| ویژگی | مقدار |
|---|---|
| عرض | ۸۰mm |
| فونت | ۱۲pt برای وزن، ۹pt برای بقیه |
| QR | ۲۵×۲۵mm |
| محتوا | شماره، تاریخ/ساعت، باغدار، محصول، وزن پر/خالی، سبد، افت، **وزن خالص درشت**، راننده، پلاک |
| نسخه | ۲ نسخه (راننده + بایگانی) |
| بازچاپ | مجاز با برچسب «نسخه دوم» و ثبت در لاگ |
