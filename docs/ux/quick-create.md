# دکمه طلایی «ایجاد سریع» (⊕)

سند مرجع: `MD-UX-002` · نسخه ۱.۰ · مالک: مدیر محصول · بازبین: مهندس UX

---

## ۱. مفهوم

دکمه `⊕` در **مرکز هدر**، همیشه در دسترس، در همه صفحات. یک کلیک = فهرست ۱۵ عملیات پرکاربرد. انتخاب = باز شدن فرم در Flyout یا Slide Modal، **بدون ترک صفحه فعلی**.

**هدف عددی:** ثبت یک موجودیت جدید (مشتری/محصول/سبد) در **≤ ۱۵ ثانیه** و **≤ ۵ فیلد**، در حالی که کاربر در فرم فاکتور است.

### ۲.۱ «ورود از اکسل» — تجربه ویژه

با انتخاب این گزینه، پنجره Import Studio پیش از انتخاب فایل باز می‌شود:

```
① فایل را انتخاب یا اینجا رها کنید  (.xlsx, .csv, .xls)
② سیستم سرستون‌ها را می‌خواند و پیشنهاد نگاشت می‌دهد
③ پیش‌نمایش ۵ ردیف اول — قابل اصلاح در همین صفحه
④ اتصال ستون‌ها به ساختار سیستم (Drag & Drop)
⑤ پیش‌نمایش کامل با وضعیت هر ردیف
⑥ ثبت
```

هرگز فایل مستقیم «ثبت» نمی‌شود؛ همیشه از پیش‌نمایش عبور می‌کند (VIS-07).

### ۳.۱ قواعد رفتار

| قاعده | جزئیات |
|---|---|
| بازگشت به زمینه | پس از ذخیره، Flyout بسته و موجودیت **در فیلد جاری فرم انتخاب** می‌شود |
| فرم اصلی دست‌نخورده | داده‌های فرم فعلی حفظ می‌شوند |
| «ثبت و جدید» | برای ورود پشت‌سرهم (مثلاً ۱۰ مشتری) |
| پیش‌فرض‌های هوشمند | شهر/گروه از آخرین انتخاب، شعبه از کاربر |
| تکرارپذیری | هر عملیات، کلید میانبر ثابت دارد |
| دسترس‌پذیری | `Alt+N` باز می‌کند، `↑↓` حرکت، `Enter` انتخاب، `Esc` بستن |
| موبایل | ⊕ به Floating Action Button پایین-راست تبدیل می‌شود |

## ۵. زیرساخت فنی

```json
GET /api/v1/quick-actions
{
  "items": [
    {
      "id": "customer.create",
      "label": "مشتری جدید",
      "icon": "user-plus",
      "shortcut": "Alt+1",
      "permission": "crm.customer.create",
      "form": "customer-flyout",
      "endpoint": "POST /api/v1/crm/customers",
      "context_fields": ["party_id"],
      "prefill": { "branch_id": "current", "group": "MARKET_TRADER" }
    }
  ]
}
```

- فهرست عملیات از سرور می‌آید و بر اساس مجوز کاربر فیلتر می‌شود.
- فرم‌ها، کامپوننت‌های مشترک‌اند (`<EntityFlyout>`)، نه کپی جداگانه.
- پس از موفقیت، رویداد `quick-create:created` با `{entity, id, label}` منتشر می‌شود و فیلد جاری آن را مصرف می‌کند.

## ۶. پذیرش

- [ ] ثبت مشتری جدید از داخل فاکتور، ≤ ۱۵ ثانیه و بدون ترک صفحه.
- [ ] پس از ثبت، مشتری به‌طور خودکار در فاکتور انتخاب شود.
- [ ] همه عملیات با مجوز کاربر فیلتر شوند.
- [ ] هر عملیات، میانبر کیبورد یکتا داشته باشد.
- [ ] «ورود از اکسل» هرگز بدون پیش‌نمایش ثبت نکند.
- [ ] در موبایل، ⊕ به FAB تبدیل و همه عملیات قابل دسترس باشد.
