# راهنمای هوشمند و Help Center

سند مرجع: `MD-UX-003` · نسخه ۱.۰ · مالک: مدیر محصول · بازبین: مهندس UX

---

## ۱. اصل

> کاربر نباید برای یاد گرفتن یک فیلد، تلفن بزند. کمک، **در محل نیاز** و در **سه سطح** است.

| سطح | زمان | قالب | مثال |
|---|---|---|---|
| ۱. Tooltip | ۰٫۵ ثانیه | متن کوتاه کنار `?` | «وزن خالص = وزن باسکول − سبد − افت» |
| ۲. راهنمای چندثانیه‌ای | ۵–۱۵ ثانیه | انیمیشن/هایلایت مرحله‌ای | «ابتدا وزن اول را ثبت کنید، سپس وزن دوم» |
| ۳. Help Center | ۱–۵ دقیقه | مقاله، ویدئو، PDF، مثال واقعی | «چگونه فاکتور با صافی صادر کنیم» |

---

## ۲. Tooltip

| قاعده | جزئیات |
|---|---|
| محتوا | حداکثر ۲۵ کلمه؛ یک جمله تعریف + یک جمله فرمول/نکته |
| دسترسی | آیکن `?` کنار برچسب + `F1` روی فیلد فعال |
| موبایل | ضربه روی آیکن (نه hover) |
| زبان | فارسی، بدون اصطلاح حسابداری خام |

**نمونه محتوای اجباری:** هر فیلد محاسبه‌شده (وزن خالص، مبلغ، صافی، مانده) باید Tooltip با فرمول داشته باشد.

---

## ۳. راهنمای چندثانیه‌ای (Coach Mark)

| مورد | محتوا |
|---|---|
| اولین ورود به صفحه | ۳–۵ گام هایلایت، قابل رد کردن |
| تغییر نسخه | فقط برای قابلیت‌های جدید |
| خطای تکرارشونده | راهنمای هدفمند پس از ۲ خطای مشابه |
| ذخیره وضعیت | «دیگر نشان نده» به‌ازای هر کاربر |

**قاعده:** راهنما هرگز عملیات کاربر را مسدود نمی‌کند.

---

## ۴. Help Center

### ۴.۱ ساختار

```
Help Center
├─ شروع سریع (۵ دقیقه)
├─ باسکول
│   ├─ ثبت قبض ورود (ویدئو ۲ دقیقه + مقاله + PDF)
│   ├─ محاسبه وزن سبد و افت
│   ├─ ابطال و برگشت قبض
│   └─ رفع مشکلات دستگاه
├─ خرید و فروش
├─ انبار و سردخانه
├─ مالی و بانک
├─ Import Studio
└─ پرسش‌های متداول / ویدئوها / دانلود PDF
```

### ۴.۲ هر مقاله شامل

| بخش | محتوا |
|---|---|
| عنوان و مخاطب | «برای اپراتور باسکول» |
| هدف | چه کاری انجام می‌شود |
| پیش‌نیاز | مجوز، داده لازم |
| گام‌ها | شماره‌دار با تصویر واقعی از سیستم (نه ماکت) |
| مثال واقعی | با اعداد مازندشت |
| خطاهای رایج | و راه‌حل |
| مرتبط | مقاله‌های بعدی |

### ۴.۳ دسترسی از داخل برنامه

| مسیر | رفتار |
|---|---|
| آیکن `?` در هدر | جست‌وجو در Help Center با پیشنهاد صفحه فعلی |
| `F1` | مقاله صفحه فعلی |
| آیکن `?` کنار فیلد | Tooltip + لینک «بیشتر بدانید» |
| خطا | پیام خطا + دکمه «راهنما» با مقاله مرتبط |

---

## ۵. جست‌وجوی هوشمند

```
ورودی: "افت بار"
نتیجه: مقاله «افت بار چیست و چگونه محاسبه می‌شود» + ویدئو + فرمول F-01
```

| ویژگی | پیاده‌سازی |
|---|---|
| مترادف‌ها | «افت»، «کسر»، «ضایعات اولیه» → یک مقاله |
| پیشنهاد زمینه‌ای | صفحه فعلی، اولویت اول |
| غلط‌یابی | فاصله ویرایشی ≤ ۲ |
| بازخورد | «مفید بود؟» و ثبت مقاله‌های کم‌بازده |

---

## ۶. آموزش و پذیرش کاربر

| مرحله | ابزار |
|---|---|
| روز اول | تور تعاملی ۵ دقیقه‌ای + ویدئو نقش |
| هفته اول | چک‌لیست کارهای انجام‌شده + راهنمای زمینه‌ای |
| ماه اول | آزمون کوتاه درون‌برنامه (۵ سؤال) |
| مستند | PDF چاپی برای اپراتور باسکول (کم‌سواد دیجیتال) |

**قاعده آموزش:** برای اپراتور باسکول، راهنمای تصویری چاپی روی دیوار ایستگاه نصب شود؛ کاربر در سرما و با دستکش، جزوه نمی‌خواند.

---

## ۷. مدیریت محتوا

| موضوع | تصمیم |
|---|---|
| محل ذخیره | `manuals/` در مخزن + جدول `sys_help_article` |
| نسخه‌بندی | همگام با نسخه نرم‌افزار |
| مالک محتوا | مدیر محصول + متخصص هر ماژول |
| بازبینی | با هر تغییر UI، مقاله همان صفحه بازبینی شود |
| زبان | فارسی؛ اصطلاح انگلیسی فقط در پرانتز |

## ۸. پذیرش

- [ ] هر صفحه، حداقل یک مقاله Help و یک راهنمای زمینه‌ای دارد.
- [ ] هر فیلد محاسبه‌شده، Tooltip با فرمول دارد.
- [ ] جست‌وجوی Help، در < ۱ ثانیه نتیجه می‌دهد.
- [ ] کاربر جدید، بدون کمک انسانی، یک قبض باسکول و یک فاکتور ثبت کند.
- [ ] نرخ «مفید بود» ≥ ۸۰٪.
