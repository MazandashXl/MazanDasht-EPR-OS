# کاتالوگ گزارش‌ها

سند مرجع: `MD-RPT-001` · نسخه ۱.۰ · مالک: متخصص علم داده · بازبین: حسابرس مالی

هر گزارش: کد، مخاطب، منبع، فیلترها، ستون‌های کلیدی، خروجی. **گزارشی که تعریف ندارد، در محصول ساخته نمی‌شود.**

قالب مشترک همه گزارش‌ها: سرصفحه (لوگو، نام شرکت، عنوان، بازه، شعبه، کاربر، زمان چاپ) · بدنه · پاصفحه (جمع‌ها، شماره صفحه، «این گزارش در تاریخ … تولید شده است»).

## ۷. قواعد مشترک گزارش

| قاعده | جزئیات |
|---|---|
| منبع | فقط داده `POSTED` برای گزارش مالی؛ پیش‌نویس در گزارش جدا |
| زمان‌بندی | همه گزارش‌ها با `business_date` فیلتر می‌شوند، نه `created_at` |
| اعداد | جداکننده هزارگان، ارقام فارسی در چاپ، لاتین در Excel |
| منفی | در چاپ `(۱٬۲۵۰٬۰۰۰)` |
| ستون انتخاب | کاربر می‌تواند ستون‌ها را مخفی/نمایش و طرح را ذخیره کند |
| خروجی | PDF (چاپ)، Excel، CSV، چاپ مستقیم |
| دسترسی | هر گزارش مجوز `rpt.<code>.view` دارد |
| لاگ | هر خروجی Excel حجیم ثبت می‌شود (BR-626) |
| Drill-down | هر عدد تجمیعی، کلیک‌پذیر به ردیف‌های سازنده |
