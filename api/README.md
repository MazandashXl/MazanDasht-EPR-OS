# قرارداد API

| فایل | محتوا |
|---|---|
| `openapi.yaml` | مشخصات OpenAPI 3.1 (منبع تولید کلاینت) |
| `examples/` | نمونه درخواست/پاسخ برای هر Endpoint مالی |

کاتالوگ کامل و قواعد: [docs/api/README.md](../docs/api/README.md)

## قواعد کلیدی
- `Idempotency-Key` برای همه POSTهای مالی الزامی است.
- مبالغ و وزن‌ها به‌صورت رشته عددی منتقل می‌شوند.
- خطاها با RFC 7807 و کد قاعده (`BR-…`) برمی‌گردند.
- هر Endpoint مجوز `PRM.*` و دامنه داده دارد.
