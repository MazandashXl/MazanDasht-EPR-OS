# سیستم طراحی و هویت بصری

| محتوا | وضعیت |
|---|---|
| توکن‌های رنگ/تایپوگرافی/فاصله | در دست تدوین |
| کتابخانه کامپوننت (Vue) | فاز ۰ |
| آیکون‌ها | فاز ۰ |
| انیمیشن‌های بازخورد (ثبت، همگام‌سازی، خطا) | فاز ۱ |
| قالب‌های چاپ | [docs/print](../docs/print/print-templates.md) |

## اصول
| اصل | معیار |
|---|---|
| خوانایی در چاپ تک‌رنگ | همه اسناد در سیاه‌وسفید خوانا |
| کنتراست | ≥ ۴٫۵:۱ |
| هدف لمسی | ≥ ۴۴×۴۴px |
| اعداد | فارسی در UI، هم‌تراز (tabular) |
| سرعت بازخورد | انیمیشن ≤ ۲۰۰ms، بدون قطع جریان |
